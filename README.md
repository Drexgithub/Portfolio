# Kiel Hedrix — Portfolio

A fast, lightweight, and modern personal developer portfolio built with HTML5, Vanilla CSS, and modern JavaScript, bundled with Vite.

## Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design Tokens), Modern JavaScript (ES6+ Modules)
- **Tooling**: [Vite](https://vitejs.dev/)
- **Zero Runtime Dependencies**: No heavy frontend or CSS frameworks for optimal performance and clean craftsmanship.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Drexgithub/Portfolio.git
   ```
2. Navigate into the project folder:
   ```bash
   cd Portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the local development server:
```bash
npm run dev
```

### Production Build

Create an optimized multi-page production build:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```
